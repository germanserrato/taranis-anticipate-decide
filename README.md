# Taranis: Anticipate & Decide

Quiero que diseñes y construyas un sitio web premium, moderno y de alto impacto para TARANIS, una plataforma tecnológica de predicción y alerta temprana frente a inundaciones.

IMPORTANTE:

No quiero una plantilla SaaS genérica.

No quiero una web corporativa convencional.

Quiero una experiencia visual de producto de nivel startup ClimateTech / DeepTech europea, comparable a las mejores webs actuales de SaaS, AI, geospatial technology y climate intelligence.

La web debe transmitir inmediatamente:

- tecnología avanzada;

- inteligencia hidrológica;

- predicción;

- agua y territorio;

- datos geoespaciales;

- inteligencia artificial;

- fiabilidad;

- capacidad de anticipación;

- apoyo a la toma de decisiones.

TARANIS debe percibirse como un PRODUCTO TECNOLÓGICO, no como una empresa de consultoría.

--------------------------------------------------

1. OBJETIVO DE LA WEB

--------------------------------------------------

El objetivo principal es vender y dar a conocer TARANIS.

La web debe conseguir que un visitante entienda en menos de 5 segundos:

1. Qué es TARANIS.

2. Qué problema resuelve.

3. Qué ventaja proporciona.

4. Que existe una plataforma tecnológica real detrás.

5. Qué debe hacer después: solicitar una demostración.

CTA principal en toda la web:

“Solicitar una demo”

CTA secundario:

“Ver la plataforma”

No utilizar “Comprar ahora”.

TARANIS es principalmente B2G y B2B y la contratación puede requerir demostración, análisis territorial, piloto o propuesta personalizada.

--------------------------------------------------

2. QUÉ ES TARANIS

--------------------------------------------------

TARANIS es una plataforma de inteligencia hidrológica y alerta temprana que permite anticipar el riesgo de inundaciones mediante la integración de:

- información hidrometeorológica;

- datos de precipitación;

- estaciones de aforo;

- radar meteorológico;

- información AEMET;

- información Copernicus;

- cartografía;

- modelos hidrológicos;

- modelos de inteligencia artificial;

- modelos LSTM;

- análisis histórico;

- predicción de caudales;

- representación geoespacial de resultados.

La plataforma transforma datos complejos en información operativa para facilitar la toma de decisiones antes y durante episodios de inundación.

Puede trabajar sobre áreas territoriales amplias y no depende necesariamente del despliegue de una red propia de sensores IoT en campo.

Está concebida para:

- administraciones públicas;

- ayuntamientos;

- organismos de cuenca;

- protección civil;

- gestores territoriales;

- operadores de infraestructuras;

- empresas que gestionan activos expuestos al riesgo de inundación.

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
