# TARANIS — sitio de producto ClimateTech

## Objetivo
Construir una web completa en español que presente TARANIS como una plataforma tecnológica real de inteligencia hidrológica, convierta la complejidad técnica en una narrativa clara y conduzca a solicitar una demo.

## Experiencia y dirección visual
- Aplicar la paleta azul noche, cian y turquesa indicada, con Sora para titulares e Inter para lectura.
- Crear una estética propia de producto geoespacial: topografía abstracta, redes de drenaje, radar, lluvia y flujos de datos; sin naranja corporativo, fotografías genéricas ni estética cyberpunk.
- Diseñar un hero oscuro de gran impacto con el mensaje exacto, un mockup vivo de TARANIS y una transición suave que convierta la interfaz en protagonista.
- Mantener contraste WCAG AA, navegación por teclado, movimiento reducido y composición optimizada para móvil.

## Home completa
- Navegación fija con selector ES/EN y accesos a todas las áreas.
- Hero, narrativa del problema, pipeline dato→decisión y presentación central del producto.
- Vídeo bajo demanda, bento de funcionalidades, simulación interactiva claramente marcada como demostración visual y perfiles de usuario.
- Diferenciación, arquitectura tecnológica, casos de uso, implantación, niveles de servicio sin precios, espacios de confianza sin datos inventados, métricas verificables, recursos, FAQ, CTA final, formulario y footer.
- Microinteracciones y animaciones CSS ligeras, con progreso de lectura y comportamiento reducido en móvil.

## Sistema y componentes
- Definir tokens reutilizables para color, tipografía, radios, sombras, espaciado, contenedores y movimiento.
- Crear componentes compartidos para navegación, botones, cabeceras, mockups, tarjetas, métricas, vídeo, FAQ, formulario y footer.
- Organizar el mockup para que futuras capturas reales puedan sustituirlo sin rehacer las secciones.

## Páginas y arquitectura
- Crear `/producto`, `/soluciones`, `/tecnologia`, `/recursos`, `/empresa` y `/contacto` con el mismo lenguaje visual y contenido inicial útil.
- Añadir metadatos únicos, OpenGraph/Twitter, canónicas, schema SoftwareApplication/Organization, robots y sitemap.
- Preparar los textos y componentes para internacionalización ES/EN, mostrando inicialmente español.

## Comportamiento del formulario
- Implementar validación y confirmación local accesible; no se persistirán ni enviarán datos todavía porque no se ha solicitado conectar un servicio de recepción.

## Validación final
- Revisar el resultado en escritorio y móvil, comprobar navegación, vídeo, FAQ, timeline, formulario, accesibilidad, ausencia de solapes y errores de ejecución.
- Hacer una pasada final de dirección de arte, UX, producto, conversión B2B y calidad frontend.
